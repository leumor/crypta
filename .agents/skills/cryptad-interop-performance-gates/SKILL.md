# Cryptad interop performance gates

Select the operation below before editing its tooling, CI, or evidence contracts.
Keep PR/local self-tests offline-safe and separate from live collectors and protected publication.
Preserve candidate identity, signatures, redaction, source provenance, and immutable published
bytes. Fixtures, self-tests, uploads, or prepared authorizations cannot prove live completion.
Never weaken a gate or baseline merely to produce a passing result.

For a component change, run its focused offline self-test; broaden for changed common schemas,
shared certification code, or release gates. A command catalog is not a requirement to run every
collector. Read all applicable protected-operation constraints before crossing that boundary.
