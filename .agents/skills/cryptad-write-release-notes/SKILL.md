# Write release notes

Use [writing guidance](../cryptad-writing-guides/SKILL.md) and
[Git policy](../cryptad-git-workflow/SKILL.md) for GitHub access.
Identify the exact integer build, source ref, previous shipped release, and requested outputs.
Drafting does not authorize editing a published Release.

- For ordinary notes, changelog artifact sets, or generated RC/GA templates, use
  [drafting](references/drafting.md). Inspect the selected release range, not all history.
- For post-GA maintenance/security-hotfix notes, also read
  [maintenance contracts](references/maintenance.md).

Stable notes are generated from authenticated frozen data. Preserve template and digest contracts,
limitations, waivers, and private incident boundaries. Never claim publication from preparation or
validation; require the applicable verified receipt. Report source, outputs, and checks.
