## Compatibility and verification

OSHI platform types use the current API, with platform-family detection delegated to `AppEnv`. Logback configuration and rolling policies retain their existing behavior. Public Platform API contracts, network protocols, and persistent formats remain unchanged.

Both Gradle builds retain strict dependency verification, including their own metadata and keyrings. The formatter versions are declared in the version catalog.

The validation results below distinguish completed local checks from Docker runtime checks,
which require an available Docker daemon.

The Docker resolver records the installed tool versions in `versions.env`. The reviewed baseline
is Codex 0.153.4, ast-grep 0.45.3, uv 0.12.10, GitHub MCP 1.12.0, actionlint 1.7.12,
Mosh 1.4.0, tmux 3.7c, Playwright 1.63.0, and ncurses 6.6. It selects stable releases at build time and shares the Playwright version between client and browser images. Base images are pulled on build. The default local Codex image label is `0.153.4`; the installed version is checked independently.

## Protected-release review follow-up

Review found two gaps beyond the ordinary build checks: the protected-release policy retained
the old Gradle version and distribution digest, and the Gradle-side JDK fingerprint parser
accepted only three-component runtime versions. The policy now matches the wrapper's 9.7.1
coordinates, and the parser accepts an optional patch component while preserving the Java 25,
build-number, and optional `-LTS` suffix requirements.

Build-logic's six tests passed, including the new JDK parsing regression cases. The protected
release and supply-chain Python modules passed all 170 tests. A new policy regression checks the
real checkout and verifies that changing either Gradle coordinate is still rejected.

Using the checksum-verified Temurin 25.0.4.1+1 distribution, the actual protected toolchain
validator returned no errors and `./gradlew --dependency-verification strict
exportStableSupplyChainResolution` passed. Generated build materials record runtime
`25.0.4.1+1`, Gradle `9.7.1`, the matching wrapper distribution digest, and strict verification.
These are local producer checks, not protected release publication or approval evidence.
